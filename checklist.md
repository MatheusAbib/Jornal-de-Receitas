- [x] Utilizar uma ou mais entidades fictícias de informação, com pelo menos 10 atributos.
- [x] Desenvolver o projeto utilizando os padrões de projeto estudados em sala de aula.
- [x] Implementar a funcionalidade de inserir registros.

- [x] Implementar a funcionalidade de excluir registros.
- [x] Implementar a consulta de registros por ID.
- [x] Implementar a consulta de todos os registros.
- [x] Implementar pelo menos uma funcionalidade que automatize um processo de negócio.
- [x] Implementar relacionamentos 1:1 entre entidades.

- [x] Propor as funcionalidades do sistema e obter aprovação do professor.
